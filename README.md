# FCVG101 Visual Inspection Assistant (CIFAKE)

## Folder Setup
1. Extract this archive into your working directory.
2. Copy the downloaded CIFAKE dataset folders (`train/REAL`, `train/FAKE`, `test/REAL`, `test/FAKE`) into `data/cifake/`.
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run Task 1 verification & generate visual outputs:
   ```bash
   python test_task1.py
   ```
